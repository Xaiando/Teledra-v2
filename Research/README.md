# Research

Owns bounded public HTTP(S) retrieval, search result extraction, source URLs,
excerpts, and durable research briefs. It rejects local/private destinations,
credentials in URLs, unsafe redirect targets, responses over 2 MiB, and long
network waits.

Research runs on a background worker and returns evidence to the court through
a typed runtime event. YouTube transcripts belong to the optional supervised
sidecar because that provider requires a separate Python package.
